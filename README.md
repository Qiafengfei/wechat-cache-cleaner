# WeChat Cache Cleaner

用 Windows 自带的组件清理微信日志和缓存。适用于 Windows 10 和 11，无需安装软件或以管理员身份运行。

## 使用

1. 从 GitHub 下载 ZIP，解压整个文件夹。
2. 双击 **清理微信.bat**。保留同目录的 `WechatCleaner.ps1`。
3. 在菜单里选清理范围，核对预览显示的文件数量和大小。
4. 如果微信正在运行，输入 `Y` 同意自动关闭微信及其后台进程，直接回车可取消。关闭后工具会重新扫描。
5. 核对清理预览，输入 `Y` 并回车可永久删除。直接回车可取消删除。

工具扫描当前用户的 `%APPDATA%\Tencent\xwechat`。默认清理 `.xlog` 日志、小程序代码缓存与图标，以及网页的 HTTP、代码和 GPU 缓存。聊天记录、登录配置、小程序本地数据、网页存储和插件元数据保留。

| 菜单选项 | 清理范围 |
| --- | --- |
| 1 | 日志和缓存 |
| 2 | 日志和缓存、小程序安装包 |
| 3 | 日志和缓存、微信已安装插件 |
| 4 | 以上全部 |

删除小程序安装包后，微信可能需要重新下载。删除插件文件后，OCR、播放器等功能可能暂时不可用，恢复取决于微信能否重新下载插件。工具保留目录结构并跳过链接。预览显示的是文件逻辑大小，实际释放空间以 Windows 为准。

自动关闭会先尝试关闭微信窗口，再结束仍在运行的微信进程。确认前可先完成正在传输的文件或通话。
